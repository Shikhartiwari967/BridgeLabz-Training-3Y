Responsive CSS Cheat Sheet

Filters

Applies graphical effects like blur or color shift to an element.

filter: drop-shadow(4px 4px 5px #ccc);

Media Queries

Applies CSS rules only when specific viewport conditions are met.

@media (max-width: 700px) { ... }

Responsive Design

A design approach ensuring web pages render well on all screen sizes using fluid grids and flexible images.

Typography

Fluidly scaling text sizes automatically using relative units or CSS math functions.

font-size: clamp(1rem, 2vw, 1.5rem);
